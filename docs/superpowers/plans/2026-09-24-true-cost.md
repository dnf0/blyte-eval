# True Cost Accounting Implementation Plan

> **For agentic workers:** Execution is delegated to headless `agy`, one task per dispatch; Claude reviews each task before the next is sent. Steps use checkbox (`- [ ]`) syntax for tracking. Do NOT `git push` or open PRs; commit locally only. NEVER start a benchmark run or call a model API: tests use stubs only.

**Goal:** Report what a run actually costs: fresh input, **cached input**, output, **and thinking**. Record cached and thinking tokens per run. Also accept the new `compact` superstate context.

**Why:** Gemini 3.8 Flash is priced at $0.75/M input, **$0.075/M cached input**, and **$3.75/M output "including thinking tokens"** (ai.google.dev/gemini-api/docs/pricing, through 2026-12-31). Both drivers count only fresh input and visible output:
- A `superstate[conversational]` run reported at $0.75 re-read 18.9M cached tokens ($1.42) and 17K thinking tokens. Its real cost is about $2.24.
- agy's JSON already reports `cache_read_tokens` and `thinking_tokens`, but `AgyCliDriver` ignores them, so agy's real cost is unknown.

Compression work cannot be judged on a number that omits the cached volume it reduces.

**Design:**
- `MODEL_PRICING` entries become `(input, output, cached)`.
- `estimate_cost_usd(model, input, output, cached_tokens=0, thinking_tokens=0) = input·in + cached·cached_rate + (output + thinking)·out`. Callers that don't pass the new arguments get exactly today's number.
- `DriverTelemetry` and `TaskRunResult` gain `cached_input_tokens` and `thinking_tokens` (default 0). Both drivers fill them in and price them.
- The turn loop sums them, and the runner records them, plus `cost_basis: "fresh+cached+thinking"`, in each result's `extra`.

**Tech Stack:** Python 3.12, pytest, ruff, pyright (basic), uv.

  2. Replace the whole `estimate_cost_usd` function with:

```python
def estimate_cost_usd(
    model: str,
    input_tokens: int,
    output_tokens: int,
    cached_tokens: int = 0,
    thinking_tokens: int = 0,
) -> float:
    """USD cost of fresh input, cached input, and output including thinking.

    Returns 0.0 for an unpriced model rather than guessing: cost per solve is a headline metric
    of this evaluation and a fabricated rate would corrupt it. Callers that pass no cached or
    thinking tokens get exactly the old fresh-input-plus-output figure.
    """
    pricing = MODEL_PRICING.get(model) or MODEL_PRICING.get(base_model_name(model))
    if not pricing:
        logger.warning(
            "No pricing for model %s: cost will be reported as $0.00, not estimated.", model
        )
        return 0.0
    in_rate, out_rate, cached_rate = pricing
    return (
        input_tokens * in_rate
        + cached_tokens * cached_rate
        + (output_tokens + thinking_tokens) * out_rate
    ) / 1_000_000.0
```
